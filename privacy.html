Privacy Policy

PatilWagh Video Automation · Last updated: 22 October 2026

PatilWagh Video Automation ("the tool") is a private publishing tool used only by the owner of the PatilWagh-GoodVibesOnly YouTube channel. This policy explains what data the tool accesses, how it is used, and how access can be removed.

1. Use of YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. Data the tool accesses

  • YouTube: basic channel information, the owner's uploaded videos and their status, and permission to upload videos, set their titles, descriptions, tags, thumbnails and scheduled publication times.
  • Google Sheets and Google Drive: only the approval spreadsheet and video files that the tool itself creates or that the owner gives it.
  • Sign-in tokens: Google OAuth tokens that let the tool act on the owner's behalf after the owner signs in.

The tool does not collect data about channel viewers, subscribers or commenters.

3. How the data is used

The data is used only to prepare, review, upload, schedule and track videos on the owner's own channel. Nothing is uploaded or scheduled without the owner's explicit approval.

4. Storage and security

Sign-in tokens and API keys are stored as encrypted secrets and are never placed in source code, logs or public files. Video records (titles, dates, video IDs and licence records) are kept in the owner's private Google Sheet.

5. Sharing

Data is not sold, rented or shared with any third party, and is not used for advertising. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

Records are kept only for as long as the owner operates the channel's publishing workflow. Stored tokens are deleted when the tool is retired or when access is revoked. Access can be removed at any time from the Google security settings page (Third-party apps & services).
